Introducción

Hoy podés transformar una idea en una landing, una calculadora, un cotizador o una herramienta para un negocio sin tener que desarrollar todo desde cero.

Pero para hacerlo necesitás entender qué hace cada herramienta y en qué momento utilizarla.

Esta guía te ayuda a elegir qué usar según el proyecto que quieras crear, cómo conectar las herramientas y qué tener en cuenta antes de publicar.

La clave no es aprender todas las herramientas al mismo tiempo. Es entender qué problema resuelve cada una.

1Antes de empezar: ¿qué querés crear?

El primer paso no es abrir una herramienta. Es definir qué necesitás construir.

Si querés crear...Por dónde empezar
Una página web simpleHTML, CSS y JavaScript
Una landing para un servicioHTML/CSS/JS o un constructor visual
Una calculadoraHTML, CSS y JavaScript
Un cotizadorHTML, CSS y JavaScript
Un diagnóstico interactivoHTML/JS y, si hace falta, una base de datos
Una aplicación webUn framework + GitHub + una plataforma de despliegue
Un prototipo sin saber programarCodex o Claude Code

Preguntas que tenés que responder

  • ¿Qué problema quiero resolver?
  • ¿Quién va a utilizar el producto?
  • ¿Qué tiene que poder hacer?
  • ¿Necesita guardar datos?
  • ¿Necesita usuarios o inicio de sesión?
  • ¿Necesita conectarse con otras herramientas?
  • ¿Quiero crear un prototipo o un producto listo para usar?

Cuanto más claro tengas el problema, más fácil va a ser elegir las herramientas.

2GitHub

¿Qué es?

GitHub es una plataforma para alojar, gestionar y versionar proyectos de código.

Permite guardar el historial de cambios, trabajar con otras personas y conectar el proyecto con plataformas de despliegue.

¿Cuándo usarlo?

Usalo cuando:

  • Querés guardar tu proyecto.
  • Vas a hacer cambios frecuentes.
  • Trabajás con IA sobre el código.
  • Necesitás recuperar una versión anterior.
  • Querés colaborar con otra persona.
  • Querés conectar tu proyecto con Netlify o Vercel.

Ejemplo

Tenés una calculadora que creaste con IA. Guardás los archivos en GitHub y, cada vez que hacés cambios, podés conservar el historial del proyecto.

Lo que tenés que entender

GitHub no es necesariamente el lugar donde el usuario final ve tu página. Es el repositorio donde gestionás el código.

Pensalo como el historial y la biblioteca de tu proyecto.

Hacé clic en "Inicia sesión" (si ya tenés cuenta) o registrate acá, completando correo, contraseña y nombre de usuario.

  • 1New — desde tu panel, entrá a crear un nuevo repositorio.

  • 4Create repository — confirmá la creación.

  • 1Agregar archivo — abrí el menú desplegable.
  • 2Subir archivos — elegí esta opción para cargar tu proyecto.

Comprobá que los archivos del proyecto aparezcan correctamente dentro del repositorio.

GitHub = donde guardás y versionás tu proyecto. Netlify/Vercel = donde lo publicás.

3Netlify

¿Qué es?

Netlify es una plataforma que permite publicar sitios y aplicaciones web. Una de sus formas más sencillas de empezar es subir directamente los archivos de un proyecto web, como HTML, CSS y JavaScript.

¿Cuándo usarlo?

Es una buena opción cuando:

  • Tenés una landing.
  • Creaste una calculadora.
  • Tenés un cotizador.
  • Querés publicar un HTML.
  • Estás empezando y necesitás un despliegue simple.
  • Querés conectar un repositorio para automatizar actualizaciones.

Ejemplo

Tenés una carpeta con index.html, style.css y script.js. Podés subir el proyecto a Netlify y publicarlo como una web.

Lo que tenés que entender

No necesitás usar GitHub para publicar un HTML sencillo en Netlify. Podés empezar subiendo directamente los archivos. GitHub se vuelve más útil cuando querés guardar versiones, trabajar con IA sobre el proyecto o automatizar los despliegues.

Pensalo como la herramienta que te permite llevar tu proyecto a internet.

4Vercel

¿Qué es?

Vercel es una plataforma para desplegar sitios y aplicaciones web. Está especialmente orientada a proyectos modernos que utilizan frameworks como Next.js y React.

¿Cuándo usarlo?

Consideralo cuando:

  • Trabajás con una aplicación web.
  • Utilizás un framework compatible.
  • Querés conectar GitHub con el despliegue.
  • Necesitás un flujo de publicación automatizado.
  • El proyecto va a crecer y tener varias funcionalidades.

Ejemplo

Creaste una aplicación web con ayuda de Claude Code. La conectás con GitHub y después con Vercel para que los cambios del proyecto puedan desplegarse automáticamente.

5Codex

¿Qué es?

Codex es una herramienta de IA para trabajar con código. Puede ayudarte a crear, modificar, entender y revisar proyectos de programación.

¿Cuándo usarlo?

Usalo cuando:

  • Tenés una idea y no sabés cómo convertirla en código.
  • Querés crear una primera versión de una web.
  • Necesitás modificar una funcionalidad.
  • Querés encontrar errores.
  • Necesitás entender qué hace un archivo.
  • Querés automatizar tareas de desarrollo.

Ejemplo

Le explicás a Codex:

"Quiero una calculadora de precios para mis servicios. Necesito que el usuario ingrese horas, cantidad de personas y modalidad, y que el sistema calcule el presupuesto."

A partir de esa indicación, podés trabajar sobre un primer prototipo y pedirle modificaciones.

Lo que tenés que entender

La IA puede ayudarte a escribir código, pero no significa que todo lo que genere esté correcto. Tenés que probar, revisar y entender lo que estás construyendo.

La IA escribe. Vos dirigís.

6Claude Code

¿Qué es?

Claude Code es una herramienta de IA para trabajar directamente sobre proyectos de código. Permite utilizar IA para desarrollar, modificar, revisar y corregir archivos de un proyecto.

¿Cuándo usarlo?

Es especialmente útil cuando:

  • Ya tenés un proyecto con varios archivos.
  • Querés modificar funcionalidades.
  • Necesitás crear componentes.
  • Querés corregir errores.
  • Vas a trabajar sobre un proyecto existente.
  • Necesitás que la IA analice distintas partes del código.

Ejemplo

Tenés una landing que ya funciona y querés agregarle un formulario de contacto. Podés trabajar con Claude Code para modificar el proyecto, incorporar la funcionalidad y revisar los cambios.

Lo que tenés que entender

No es solamente conversar sobre programación. Es una forma de trabajar con IA sobre el proyecto.

No reemplaza tu criterio. Te ayuda a desarrollar.

8¿Y si tu herramienta necesita usuarios o guardar datos?

Un HTML publicado en Netlify alcanza para una landing, una calculadora o un cotizador que se usa y se cierra. Pero si querés que cada persona entre con su cuenta, guarde lo que hizo y lo encuentre al volver, necesitás una parte más: un backend, es decir, funciones que corren en un servidor y una base de datos.

Cloudflare Pages

Cloudflare Pages publica tu web igual que Netlify o Vercel, conectada a GitHub. Además permite sumar funciones (el login, guardar y leer datos) y una base de datos (D1) en el mismo proyecto, con un plan gratuito generoso.

10¿Qué podés crear?

Estas herramientas pueden ayudarte a desarrollar diferentes tipos de productos digitales.

Landing pages

Una página para presentar un servicio, curso o negocio.

Calculadoras

Una herramienta que procesa datos y devuelve un resultado.

Cotizadores

Un sistema que calcula precios según variables que ingresa el usuario.

Diagnósticos interactivos

Un formulario que permite responder preguntas y obtener una devolución.

Herramientas para negocios

Soluciones digitales para resolver tareas específicas.

Lo importante

No necesitás empezar con una aplicación enorme. Podés construir una primera versión pequeña, probarla y después agregar funcionalidades.

11¿GitHub es obligatorio?

No. Si tenés un HTML y querés publicarlo rápidamente, podés empezar directamente con Netlify.

Pero GitHub es muy útil cuando:

  • El proyecto crece.
  • Vas haciendo cambios.
  • Trabajás con IA.
  • Querés mantener historial.
  • Necesitás colaborar.
  • Querés automatizar despliegues.

Proyecto pequeño: podés empezar sin GitHub.
Proyecto que evoluciona: GitHub empieza a tener mucho más sentido.

12¿Qué necesito para empezar?

No necesitás dominar todas las herramientas. Podés comenzar con:

  • Una idea concreta.
  • Una computadora.
  • Una herramienta de IA para ayudarte con el código.
  • Un proyecto pequeño.
  • Una plataforma para publicarlo.

Recorrido recomendado

  1. Definí qué querés crear.
  2. Pedile a la IA que te ayude a construir una primera versión.
  3. Probá que funcione.
  4. Guardá el proyecto si vas a seguir desarrollándolo.
  5. Publicalo en Netlify o Vercel.
  6. Mejoralo a partir de lo que aprendiste.

Preguntas frecuentes

¿Necesito GitHub para publicar una página?

No necesariamente. Un HTML sencillo puede publicarse directamente en Netlify.

¿Necesito usar Netlify y Vercel?

No. Son alternativas de despliegue. El proyecto determina cuál tiene sentido.

¿Necesito GitHub para usar Vercel?

No necesariamente en todos los escenarios, pero GitHub es especialmente útil para trabajar con repositorios y despliegues conectados.

¿Si entro a Vercel con GitHub ya tengo una base de datos?

No. GitHub y la base de datos cumplen funciones diferentes.

¿Dónde está publicada mi página?

En la plataforma de despliegue que hayas elegido: Netlify, Vercel u otra.

¿Dónde está guardado mi código?

Puede estar en tu computadora y/o en GitHub.

¿Puedo crear todo con IA?

La IA puede ayudarte muchísimo a construir código, pero necesitás definir qué querés crear, probarlo y revisar el resultado.

¿Codex y Claude Code hacen lo mismo?

Tienen capacidades que se superponen, pero funcionan dentro de entornos y flujos diferentes.

¿Puedo empezar sin saber programar?

Sí. Podés comenzar con proyectos pequeños y utilizar IA como asistencia.

¿Qué pasa si mi proyecto necesita usuarios, pagos o una base de datos?

Ahí ya no estás solamente ante un HTML estático. Vas a necesitar considerar backend, autenticación, base de datos, APIs u otros servicios según lo que quieras construir. Mirá la sección ¿Y si tu herramienta necesita usuarios o guardar datos?

Conclusión

No necesitás aprender a programar todo desde cero para empezar a crear productos digitales.

Pero sí necesitás entender qué hace cada herramienta y cómo utilizarla.

La tecnología te permite transformar una idea en algo que funciona.

Una propuesta puede ser un PDF. Pero también puede ser una landing, una calculadora, un cotizador o una herramienta personalizada.

La clave es saber qué construir, con qué herramienta y cómo dirigir el proceso.

¿Querés seguir aprendiendo?

Si esta guía te ayudó a entender el ecosistema, el próximo paso es elegir una idea pequeña y empezar a construir.

No hace falta esperar a saberlo todo.
